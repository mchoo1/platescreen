## Schema note (deviation from task assumptions)

The task brief assumed Stride's `sgFoodDb.ts` exports three target arrays — `SG_RESTAURANTS`, `SG_GRAB_AND_GO`, `SG_GROCERY`. As read on this run, **Stride only has a single `SG_RESTAURANTS` array** (`app/src/lib/sgFoodDb.ts`, line 718) holding every outlet type (`restaurant` / `grab_go` / `food_court` / `ready_to_eat` / `supermarket`), distinguished by the `outletType` field. There is no separate grab-and-go or grocery array in the live file — those only exist as standalone JSON source files under `database/grab-and-go/` and `database/restaurants/` (not yet imported for grab-and-go equivalents beyond what's already in `sgFoodDb.ts`). All snippets below target `SG_RESTAURANTS`, matching what actually exists.
