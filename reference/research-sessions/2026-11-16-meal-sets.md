# 2026-11-16 — Meal sets (McDonald's Extra Value Meals) + home-cooked hidden

## What changed
- Home-cooked recipes hidden from search, sitemap and static pages (`HIDDEN_OUTLET_TYPES`). Data kept.
- 13 McDonald's EVMs added as `meal_configurations` (main / side / drink, pick one each) by `scripts/add-mcd-meals.ts` (idempotent).
- New components: Fries S/M/L, Coke Less Sugar (S), Coke Zero (S) — official McDonald's SG pages; Coke Zero from Coca-Cola per-100 ml data.
- Search: a set is one row with 6 combinations. Filters show the default meal if it fits, else the cheapest fitting combination ("Fits with Corn Cup + Coke Zero").
- Incomplete totals: a maximum (kcal, carbs, fat) can never be confirmed; a minimum (protein) can be met by the lower bound.
- New page `/brand/[id]/meal/[configId]` with an interactive builder; dish pages link "Also as a meal".

## Data honesty
- Set prices: McDonald's SG does not publish EVM prices online. Stored the consensus from menu-listing sites as `web_research`, shown as "unconfirmed". `lastVerifiedAt: null`.
- Corn swap = $0 (McDonald's press release, 2019). Large-fries and Coke Less Sugar swap prices unknown → combination price shown as "Price not known", never guessed.

## Deferred
- KFC, Jollibee, Texas Chicken, Popeyes, MOS, Subway: no official nutrition per component or meal composition found. Their existing flat set rows stay searchable as before.
